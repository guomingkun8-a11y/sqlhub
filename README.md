# SQLHub

SQLHub 是面向业务团队的智能数据分析工作台。用户可以像和同事交流一样提问：普通对话直接回答，涉及数据时再查询已连接的数据源，并根据问题返回文字、表格、图表或进一步分析。

## 产品能力

- **自然对话与问数**：理解问候、普通问题、数据查询和分析追问，不要求用户先选择固定模式。
- **按需呈现结果**：根据问题和查询结果选择表格或图表；用户明确指定展示形式时优先遵循。
- **逐步调查问题**：对趋势和原因类问题，可以基于前一步证据追加只读查询，并用实际数据说明发现、可能解释及尚未验证之处。
- **延续会话上下文**：在同一会话中引用先前查询结果，支持针对结果继续提问。
- **数据访问控制**：按用户和工作空间检查数据源访问范围，并在查询前验证表、字段和只读 SQL；支持配置的数据权限规则。
- **业务语义配置**：可维护业务术语、SQL 示例和提示词，帮助模型理解组织内的指标与表达。
- **多种接入方式**：提供网页聊天、MCP 接口和飞书机器人。飞书机器人按已关联的用户身份查询，并将群聊结果私聊发送给提问者。

## 工作方式

SQLHub 先判断消息是否需要访问数据。普通聊天不执行 SQL；数据问题使用当前会话的数据源，或在当前工作空间选择可用数据源。查询通过权限校验和只读检查后执行，再由模型结合查询证据撰写回答。分析过程有查询次数和结果大小限制。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `backend/` | FastAPI 服务、数据访问、安全查询、智能体和迁移 |
| `frontend/` | Vue 3 网页应用 |
| `g2-ssr/` | 服务端图表渲染 |
| `installer/` | 安装与服务管理资源 |
| `docs/` | 开发与维护文档 |

## 开发环境

后端使用 Python 3.11，前端使用 Node.js。运行服务前需要准备 PostgreSQL，并按项目配置设置模型、数据库及其他依赖。

```powershell
cd backend
uv sync
uv run uvicorn main:app --host 0.0.0.0 --port 8000 --workers 1
```

另开终端启动前端：

```powershell
cd frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 3333
```

后端测试：

```powershell
cd backend
uv run pytest -q
```
